Can't load resources

The connection is in config.js, next to this page. To fix it:

  1. Make sure you have the latest code (git pull), which includes config.js.
  2. Serve the repo folder over HTTP, for example with npm run dev, and open http://localhost:5173/finder.html.
  3. If the Supabase project has changed, update SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY in config.js. A teammate in the KAVI Supabase organization can find both in the Supabase dashboard under Project Settings → API Keys.

Never put the secret key (sb_secret_…) in config.js: this page sends it to every visitor. Full steps are in README.md under "Running the resource finder".
